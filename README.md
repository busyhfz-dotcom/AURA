# Market Sentinel

پنل فارسی پایش بازار رمزارز و فارکس. این مخزن وضعیت نسخهٔ اولیهٔ منتشرشده در [سایت خصوصی Market Sentinel](https://market-sentinel.somayehfarhzad.chatgpt.site) را ثبت می‌کند.

## قابلیت‌های موجود

- نمایش نمودار و قیمت BTC، ETH، SOL و XRP از Coinbase Exchange، در صورت دسترسی به منبع داده
- بازبینی بازار هر ۶۰ ثانیه، فقط هنگام باز بودن صفحه
- تحلیل روند EMA ۲۰ و ۵۰، RSI ۱۴، ATR و شکست محدودهٔ ۲۰ کندل
- نمایش ورود، حد ضرر و هدف ۱:۲ فقط وقتی تمام شرط‌ها و تازگی داده برقرار است
- محاسبهٔ حجم نظری بر اساس سرمایه و درصد ریسک
- مسیر آمادهٔ دادهٔ فارکس از OANDA، مشروط به ثبت امن کلید و شناسهٔ حساب در محیط سرور

## محدودیت‌های این نسخه

اتصال حساب معاملاتی، ورود مستقل کاربران، پایش پس‌زمینه هنگام بسته بودن صفحه، هشدار، اجرای معامله، فیلتر خبر، آزمون تاریخی و آمار عملکرد واقعی هنوز پیاده‌سازی نشده‌اند. سیگنال‌ها تضمین سود یا توصیهٔ شخصی معامله نیستند. اگر دادهٔ معتبر در دسترس نباشد، پنل سیگنال صادر نمی‌کند.

## اجرا

Node.js 22.13 یا جدیدتر:

```bash
npm ci
npm run dev
```

برای اتصال آزمایشی OANDA، متغیرهای `OANDA_API_TOKEN` و `OANDA_ACCOUNT_ID` را به‌صورت محرمانه روی سرور تنظیم کنید؛ `OANDA_ENVIRONMENT=live` فقط برای محیط واقعی است. هیچ کلیدی را در مخزن ثبت نکنید.

## کد

رابط در `app/page.tsx`، دریافت داده در `app/api/market/route.ts` و منطق تحلیل در `lib/analysis.ts` است.
